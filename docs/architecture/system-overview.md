# System Overview

## Project

BookLoverECommerce is a microservices-based e-commerce platform built with ASP.NET Core 10.

The project is initially developed as a university course project and is designed to evolve into the commerce platform of the BookLovers ecosystem.

---

## Objectives

- Learn Microservices Architecture
- Learn Clean Architecture
- Learn API Gateway
- Learn Docker
- Learn PostgreSQL
- Learn JWT Authentication
- Build a production-ready portfolio project

---

## Technology Stack

| Technology | Purpose |
|------------|---------|
| ASP.NET Core 10 | Backend Framework |
| PostgreSQL | Database |
| Entity Framework Core | ORM |
| YARP | API Gateway |
| Docker | Containerization |
| JWT | Authentication |
| GitHub | Source Control |
